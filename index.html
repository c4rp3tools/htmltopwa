3 Instrucciones para GitHub

📋 Pasos para publicar en GitHub Pages

  1. Crear repositorio: Ve a github.com/new y crea un repositorio público.
  2. Subir archivos: Sube todos los archivos descargados.
  3. Activar GitHub Pages: En el repositorio ve a Settings → Pages, selecciona main y guarda.
  4. Acceder: Tu app estará en https://TU-USUARIO.github.io/NOMBRE-REPO/
💡 Tip: Si tu repositorio se llama mi-pwa, la URL será:
https://TU-USUARIO.github.io/mi-pwa/

📱 Instalar la PWA

  1. En Android (Chrome): Abre la URL, toca los 3 puntos → "Agregar a pantalla de inicio".
  2. En iOS (Safari): Abre la URL, toca el botón compartir → "Agregar a pantalla de inicio".
  3. En PC (Chrome/Edge): Aparecerá un icono ⊕ Instalar en la barra de direcciones.

📦 Generar APK (para Android)

  1. PWABuilder: Ve a pwabuilder.com.
  2. PWA2APK: pwa2apk.com.
  3. Bubblewrap: npm install -g @bubblewrap/cli y luego bubblewrap build.
